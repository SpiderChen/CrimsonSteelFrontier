# 实时 3D 机甲

战场、训练场、整备预览与动作检视使用实时三维骨骼模型。现有机甲 PNG 仅保留作机库收藏卡片；战斗不再读取其像素轮廓，也不再用网格拉伸整张图片。

模型采用原创低多边形硬表面风格，通过可编辑的 Godot 源文件构建，没有下载外部模型或更改系统配置。

当前造型按用户要求采用高达式日系机甲，并将三种王牌风格分别接入三台机体：赤鸢为红白火力型，使用散热背架与分层散热翼；夜莺为紫白高速近战型，使用较小头部、窄身、四片展开式长翼；白隼为白蓝金重装骑士，使用金边厚肩甲和层叠装甲披肩。斜切胸甲、前额 V 形天线、独立双眼和面罩形成共同设计语言。静止时重心略偏移，双脚前后错开，移动时平滑过渡至原 IK 步态。背部结构是机体装甲/散热部件，不会凭空增加炮击或伤害；手持武器按实际配装显示。这些造型角色不改变机体数值、武器选择或玩家存档。

持械分为放松、接敌抬枪、射击和收势。每只手按自己的射程和实际攻击事件驱动，拳套与盾牌不再默认使用举枪姿势；持续光束保持瞄准，已飞出的导弹不锁住手臂。放松时枪口斜向下，攻击结束后平滑放下；近战起手和收招也与放松姿势衔接。检视页默认关闭攻击，提供独立“攻击演示”开关。武器按类别放大，步枪使用深色主体和浅色护壳，导弹保留四联发射管与黄色标识，能量剑加宽并改为粉色光刃。所有效果仍取缩放后真实枪口和剑尖挂点。

以下为此前造型返工记录：

2026-11-11 造型重做：依据已有三台机甲立绘重新制作多边形轮廓装甲，替换原先用于主体的倒角方盒。收紧腰部、延长腿部，增加分层胸甲、斜面头盔、独立面罩、关节轴盖、液压杆和散热格栅；赤鸢使用红白装甲与双涡轮，夜莺使用细长紫色尖翼和琥珀色灯，白隼使用白蓝重甲与分段背部环。枪壳、尖头剑和手盾同步调整。材质改用逐像素金属高光，增加自身投影，整备预览分辨率提高至 512。仍为风格化程序模型，不等于原立绘的高精度建模与贴图。

- `scripts/rig/mech_geometry.gd`：带倒角的装甲网格及金属、发光材质。
- `scripts/rig/mech_rig_3d.gd`：赤鸢、夜莺、白隼的比例、装甲、背包、15 根骨骼、武器几何和骨骼动画。机械装甲使用单骨骼权重的 GPU 蒙皮，肢体长度保持不变；躯干、腿部按材质合批，武器挂点仍随骨骼运动。
- `scripts/rig/mech_projection.gd`：屏幕方向与相机地面的转换，使八方向瞄准和支撑脚匹配实际地图位移。
- `scripts/rig/mech_viewport.gd`：正交相机、灯光及透明渲染目标。每个可见机甲按当前姿态实时渲染，再合成到现有 2D 地图；不是预烘焙序列帧。关闭界面时模型与渲染目标一起释放。
- `armor_shield.gdshader`：跟随同一装甲几何和骨骼的边缘护盾，来弹侧短暂发光，不铺满身体中心。

骨骼为 pelvis → chest → head；每侧另有 hip → knee → ankle 和 shoulder → elbow → wrist。双腿使用两段 IK，行走、跑动分别计算支撑与抬脚；速度变化平滑混合，转向连续旋转。上身瞄准与腿部移动分离，后撤仍朝向目标。剑、拳、锤响应真实出手时序，剑光带采样实际 3D 剑尖，枪口光束取真实武器挂点。

悬浮收腿并点亮推进器；冲刺使用推进姿态；履带替换行走腿并滚动履带片。躯干、核心、背包和两手武器外观反映当前配装。远程武器将屏幕目标投射到三维瞄准平面，调整手腕让枪管与实际射线对齐。程序动作不等同于动作捕捉或专门制作的逐帧角色表演。

实现参考：[Godot Skeleton3D](https://docs.godotengine.org/en/stable/classes/class_skeleton3d.html)、[BoneAttachment3D](https://docs.godotengine.org/en/stable/classes/class_boneattachment3d.html)、[Spatial shaders](https://docs.godotengine.org/en/stable/tutorials/shaders/shader_reference/spatial_shader.html)。

## 战舰与敌军

`unit_model_3d.gd` 构建战舰、守卫、突击兵、炮兵、无人机与四个区域 Boss 的原创硬表面模型；`unit_viewport.gd` 提供透明正交渲染；`unit_art.gd` 按画布管理可见实例。船桥、探索、首领地点、首领战和训练敌军均使用实时 3D。动态腿部、履带、炮台和核心独立保留，其余几何按材质合批。模型源文件位于 `scripts/rig/`。

战舰固定驻守，旧存档保留船位并清除旧航行目标；默认以舰体为中心自动攻击650范围内最近敌军。三台机甲基础移速调整为190／160／130，装备、环境、负载与冲刺仍作用于实际速度。
