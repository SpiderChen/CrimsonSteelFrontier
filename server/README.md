# 云档案服务

项目自带可运行的账号、云存档与回收结算后端，使用 Python 标准库和 SQLite。所有数据库、备份和运行文件均放在项目内，不安装系统服务。

母舰改造存档会校验 `carrier.levels` 的主炮、维修、补给舱等级（1—5）；旧存档补齐一级模块。副本支援次数、冷却与待落弹随 `expedition.run.support` 保留。更新 `economy.py` 后需重启已有后端进程使校验生效。

自由探索使用 `expedition.run.schema = 2`，云端保留地图种子、已探索区域、发现/使用的地点、击破记录与整趟支援。旧版路线中途存档由客户端迁移为安全回舰并结算已有赏金；上传迁移后的档案后可继续跨设备同步。

## 启动

在项目根目录运行：

```sh
./start_cloud.command
# 浏览器打开 http://localhost:8070
```

默认数据库为 `.local/cloud.sqlite3`，H5 文件来自 `build/web`。项目的 `play.command` 也会启动此服务，使用原试玩端口8060。母舰首页 → 舰务与档案 → 云端档案，可创建账号、保存当前进度，或在另一设备登录并下载。首次迁移封存本机已积累的回收收益；之后的时间累计与结算由服务器负责。改动装备和探索进度后，应在换设备前保存到云端。

更新 `server/catalog.json` 或 `server/economy.py` 后，需停止并重新启动后端进程，才能加载新增近战、手持盾牌目录和旧收藏合并为锁定的规则。已有数据库和账号可以继续使用。

局域网调试可以使用：

```sh
./start_cloud.command --host 0.0.0.0
# 其他设备打开 http://这台电脑的局域网IP:8070
```

互联网部署时，把整个服务放在已有 HTTPS 反向代理之后，使用同域静态页面与 `/api`；数据库目录应位于持久存储上。项目没有申请或发布互联网后端域名。已有 Sites 静态页面仍是此前发布版本，尚未配置这个后端。

若静态页面与后端分开托管，在母舰输入完整 `https://后端域名/api`，启动服务时用 `--allow-origin https://静态页面域名` 显式允许该来源。支持重复提供多个来源；默认不开放跨域。

## 同步与领取规则

- 账号密码采用随机盐和 PBKDF2-HMAC-SHA256（600000次）存储；服务端只保存会话令牌的哈希，登录会话有效期30天。密码不会保存在客户端。
- 云档案带递增版本。上传、领取均在 SQLite 事务中检查版本；旧设备不能覆盖新设备的进度。下载前写入本机 `.before_cloud.json` 备份。
- 已存在的云档案使用服务器保存的回收账本。上传中的客户端时钟、累计时长、未领金额和领取次数不会替换它。切换回收方案时，先按原方案累计到当前服务端时间，再启用新方案；既有认证快照保持不变。
- 云账号在认证档案里切换方案时会立即联网同步，无需再手动保存。未登录或未同步最新档案时拒绝切换；网络中断时保留原方案，并提示检查云端状态。
- 领取请求使用持久的随机请求编号。奖励、装备、溢出仓与收据一起提交；响应丢失后用同一编号重试会返回原收据。另一个请求携带旧版本会被拒绝。
- 领取由服务端生成区域装备、词条、机制、研究资料和样本；按24/72小时规则积分，保留分账和小数余量。自动分解只处理本次精良掉落，稀有以上保存在背包或溢出仓。
- 绑定云账号后的本机档案需要联网领取，退出登录不会转为本机发奖。无账号的原本机模式仍可使用。
- 结算结果未确认时暂停战斗，保留恢复入口和请求编号。可重试结算，或下载服务器上的最新进度。
- 若待确认期间会话失效，可在原服务重新登录原账号，再恢复同一笔结算；此时不会允许把请求转到其他账号或服务。

战斗与探索目前仍在客户端执行，认证费率由服务端根据三次记录重新计算。这一版本提供可信计时、事务、防重复领取和账号隔离；战斗记录的反作弊验证需要另行接入服务端战斗计算。

## 数据与维护

- `.local/cloud.sqlite3`：账号、会话、存档和领取收据。停止服务后备份这个文件；在线备份可使用 SQLite 的 backup API。
- `server/catalog.json`：从 Godot 的部件、兼容池、区域数据导出，避免两端手工维护不同掉落表。修改部件规则后重新生成：

```sh
./tools/Godot.app/Contents/MacOS/Godot --headless --path . --script tests/export_cloud_catalog.gd -- --test
```

- 客户端 `cloud_session.json` 与游戏存档分开保存；游戏快照只含账号绑定和版本，不含令牌。
- 后端源码和数据库被排除在 H5 资源包之外。

## 验证

```sh
python3 -m unittest server.test_server -v

# 以下联网专项使用独立测试数据库：先保持此进程运行
python3 server/app.py --port 8071 --database tests/cloud-integration.sqlite3 --allow-origin http://localhost:8060

# 另一终端：真实 Godot HTTP 客户端与两个独立浏览器会话
./tools/Godot.app/Contents/MacOS/Godot --headless --path . tests/test_runner.tscn -- --test --cloud-only
node tests/cloud_browser.cjs
```

浏览器专项会在测试数据库中模拟48小时离线，并模拟一次服务端提交后网络响应丢失，不修改系统时间或正式数据库。
