# 绯红战线 · CRIMSON FRONT

Godot 4.7.2 制作的 **2D 竖屏机甲放置游戏**。720×1280 设计画布，9:16 等比例适配；手机触控和桌面鼠标均可操作。六位成年二次元女性机师，游戏内无充值入口。

## 试玩

此前发布的私有在线版本：https://crimson-front-mecha.sound-kite-4266.chatgpt.site （登录当前账号访问）。本次新增机制、工坊、战术、区域航线、挂机认证、机师成长与云档案已更新本地 H5，尚未重新发布到此地址。

macOS 双击 `play.command`，浏览器打开 `http://localhost:8060`。也可在项目目录执行：

```sh
python3 server/app.py --port 8060 --open
```

双击启动器会在后台运行服务；关闭启动窗口不影响试玩，再次启动会复用当前项目的服务。后台日志保存在项目的 `.local` 目录。

手机本地试玩：执行 `python3 server/app.py --port 8060 --host 0.0.0.0`，让手机和电脑连接同一 Wi-Fi，手机浏览器打开 `http://电脑局域网IP:8060`。

H5 应通过 HTTP/HTTPS 打开，不能双击 HTML 用 file:// 加载 WASM。推荐支持 WebGL 2 的近期 Chrome、Safari。单线程构建不要求 COOP/COEP；标准导出目录约 66 MiB，托管压缩包约 28.5 MiB。竖屏比例始终保持，宽屏设备两侧留边。

机库共六台机体，新增苍狼（移速210、矢量游击）、曜隼（移速145、射程+25%、供能+12）和玄甲（移速110、载重+40、护盾+24）。在「整备 → 机库」翻到第二页换乘，每台独立保存等级、词条、装备和战术预设。

新增雷娜（格斗增伤与近距离斩击）、星澜（追踪导弹与目标标记）、伊芙（排热、临时护盾与能量恢复）。机师页第二排可查看立绘、技能和个人任务；未拥有的机师可消耗300游戏内星晶定向招募。每人有三项个人任务和三段信赖交流，也加入常驻随机招募池。旧三人存档、机体成长、配装和挂机认证均可继续使用。

## 操作与玩法

母舰首页突出「副本作战」，常用设施保留机甲整备、部件仓库、机师和前线回收四项。制造、训练、配装与自动战术从「机甲整备 → 构筑工坊」进入，招募从机师页进入；战舰指挥、样本兑换与行动任务归入「舰务」，云存档与航行日志归入「档案」。任务可领奖、溢出仓有物品时才在首页显示提示，溢出仓也可从部件仓库进入。按钮使用切角装甲主题，出击、设施、普通操作和仪表工具采用不同轮廓，并包含按下、悬停、禁用与键盘焦点反馈。

- **武器战斗方式**：武器自动决定攻击节奏，每只手独立运作，无需额外动作按钮。连射炮移动时缩短轮次间隔并连续打出三发；轨道炮与脉冲光束蓄能后自动开火，停步时蓄能需0.65秒，移动时按35%速度蓄能；换目标或超出射程会清除蓄能；导弹可在移动中完成0.4秒锁定并自动追踪发射，换目标重新锁定；持续激光维持照射，等离子炮命中后范围爆破；能量剑扇形横斩，拳套三段独立命中，战锤较长前摇后重击。蓄能与锁定使用战场准星直接反馈，训练和认证使用相同规则。
- **武器特效**：连射使用锥形枪焰与炽热曳光，轨道炮沿实际飞行轨迹留下电弧和短暂余迹，等离子具有聚能光核、旋转电环和命中爆破，导弹带追踪烟迹与尾焰；激光/脉冲具有分层束芯、流动光丝与接触火花。剑光按真实剑尖采样并渐隐，拳套和重锤分别增加冲拳气流与冲击碎屑。所有动画由模拟时间驱动，暂停、半速和重新开始保持一致；实战和训练复用绘制，数量与存活时间均有上限。「动作与特效检视」可切换九类武器。
- **机师常驻展示**：母舰首页显示当前主战机师大立绘与随信赖、修复状态变化的待机台词，点击立绘直接打开对应机师档案；整备页同屏展示机师与机甲，战场下方使用更大的机师头像，归航报告由机师反馈本次结果。展示不新增剧情弹窗，也不暂停战斗。
- **界面分层**：页面无常驻底部导航栏。母舰首页按“整备与构筑、机师与成长、舰队支援与回收、舰务与档案”四组展示全部15个设施，无需展开菜单或滚动。战舰指挥、物资兑换、制造、仓库、训练、配装、战术、招募、任务、剧情与云档案可直接进入。整备、机师和招募页通过左上角返回母舰。首页底部“副本作战 · 选择地图”统一出击；战场直接显示舰炮、维修支援，副本进度与首领部位按当前战斗显示。
- **扩大战区**：新出击地图为7168×5632，宽高各为此前两倍、总面积四倍；保留降落点周围的补给和敌营，并向北、向东增设敌营、设施与首领区域。探索进度按616格迷雾计算。进行中的旧版地图保留原布局、船位、损伤与设施状态，回舰后下次出击进入大地图。
- **副本地图**：母舰首页通过“副本作战 · 选择地图”进入整张地图自由探索，不再选择路线或自动推进节点。四张地图各有环境、地形、敌人与掉落池，敌营和设施散布其间，首领位置随地图生成。地图支持浮动摇杆、双指拖动/缩放；桌面支持 WASD/方向键、右键拖图和滚轮缩放。
- **探索与走位**：新地图默认停留在降落点，探索方向由玩家决定。自动战斗负责附近选敌、接敌、开火与首领避险；配装自适应按主手武器和机师选择游击或停步射击，近战优先贴身接敌；无敌人时显示“自动战斗待敌”，不会自动探索未知区域或寻找首领。切到手动立即取消自动路线，摇杆或方向键接管，松手停止；两种模式均自动开火。镜头移开后点“定位机甲”恢复跟随。旧版自由战区存档仍保留原巡航行为。
- **自动战术**：母舰首页“整备与构筑 → 自动战术”或战区右上“更多”内的“自动战术”可调整目标优先、交战距离、热量策略、生存策略与技能时机。自动巡航按设置走位，手动接管后松手会停止；自动选敌与火控仍使用当前战术。精英以金色轮廓和“精英”标记显示，有更高装甲与火力。
- **发现与挑战**：依次解锁赤锈军工区、白噪冷却站、沙海试验场、坠落轨道港。机甲实地接近才会揭开地图迷雾、发现地点，拖动镜头不会开图。发现首领后可先继续搜集，靠近并主动选择挑战才会开战，没有清场或路线前置要求。首领就在发现的位置战斗，结束后回舰结算。样本兑换位于母舰“副本物资”。
- **母舰改造与支援**：舰载主炮、维修无人机、战术补给舱各有1—5级，改造消耗 C600×当前等级、合金20×当前等级。基础每趟炮击2次、维修1次，共用30秒冷却。舰炮锁定落点，1.2秒后在180范围内造成140基础伤害；每级增加70伤害、10范围。维修恢复20装甲并排热25，每级增加5。补给舱每级减少2秒冷却，Lv.3和5各增加一次炮击和维修。战场直接显示支援按钮；整张地图共用支援次数，新探索重新装填，读档保留次数、冷却和待落弹。
- **设施与撤离**：靠近武器库、补给残骸和冷却设施后，点击“交互”自行选择。冷却设施提供90秒散热+40%、移速-20%；武器库可提供定向稀有部件，但提高首领炮击密度；补给可选维修或材料。每处只用一次。装备、已结资源和样本即时保存，损毁只损失未结赏金，主动撤离结算全部赏金。中途读档保留布局、迷雾、设施使用和敌军损伤；回舰后下次进入重新生成地图。旧版进行中的节点路线会安全回舰，结算已有赏金并保留装备、样本与地图解锁。
- **地图交互**：移动中自动索敌射击，行走和开火互不锁定；出射程停火，敌军发现玩家后追击并独立开火。技能满能后自动释放，也可点击技能按钮。击破目标不会打断正在按住的移动。“探索概览”只展示已有情报，不会改变探索或替玩家选择地点。
- **战舰定点警戒**：绯红方舟固定在降落点，不再飞入、追随或移动。火力警戒每6秒自动攻击舰体650范围内最近的敌军，基础伤害24、消耗6舰能；无需机甲正在交战。近舰防护为650范围内的机甲补充临时护盾，静默待命保留舰能。旧存档保留战舰当前位置，取消未完成航行。
- **舰队战术指令**：每趟初始舰能60、上限100，基础每秒恢复3；指令共用10秒冷却，与原有重型支援冷却分开。40舰能发动三轮齐射，每轮基础35伤害、范围150，落点锁定后延迟结算；30舰能在当前位置展开半径190、持续8秒的屏障，范围内承伤降低35%；45舰能在战舰原地开启驻舰补给站。主炮升级强化护航和齐射，补给舱升级提高舰能恢复。
- **驻舰补给与归航**：开启补给后，机甲在160范围内、周围420范围无敌军且不在首领战时，可接受每秒2装甲维修与4排热，每秒消耗2舰能；维修模块升级提高修复速度。补给不结束探索，之后可恢复定点警戒。每趟归航自动展示战舰贡献，包括实际输出、减伤、维修与部署次数；战舰指挥可继续查看上次记录。舰能、船位、待落弹、屏障时间和贡献随存档恢复。
- **母舰大本营**：绯红方舟提供恢复、机库整备、改造和设施，通过“母舰回航”停泊，通过“副本作战 · 选择地图”选择地图与定向型号后出击。
- **损毁与复活**：装甲归零后由母舰回收，在母舰内修复5秒并满装甲复活。输入、路线与巡航停止，需重新选择副本；地图解锁、装备和养成进度保留，修复状态也会存档。旧版进行中的自由战区或独立首领存档仍可完成并回舰。
- **独立机库**：母舰“机甲整备 → 机库·更换机体”可查看三台独立机体并自由换乘，机师另行选择。赤鸢基础移速190、散热+8/秒，适合机动突击；夜莺基础移速160、远程射程+15%，自动接敌后停步射击；白隼基础移速130、载重+25、基础护盾+12，自动战斗稳守阵地。装备移速、负重、区域环境和冲刺继续影响实际速度，整备页同时显示基础与当前移速。每台生成两条不重复的机体随机词条，涵盖火力、散热、载重与供能，生成后固定保存。机体各自持有六槽部件、等级、三套配装预设及战术；换机师不改变机体与装备，换机体不改变机师。机体强化每级增加 7 火力，不改变机师等级和机体词条；机师仍在档案页单独成长。
- **机甲部件**：左手武器、右手武器、躯干、腿部、核心、背包六个槽位，每台机甲独立配装、共用仓库。精良/稀有/史诗部件分别有 1/2/3 条不重复随机词条，品质概率为 60%/30%/10%。词条包含火力、攻速、移速、减伤、暴击、技能充能；主战机甲的部件即时生效。减伤上限 65%，攻速词条上限 50%，暴击率上限 75%。新旧存档均赠送六槽初始配装（含左手连射炮、右手轨道炮、散热背包），以及备用冲刺推进器。
- **部件特性**：实弹连射、轨道贯穿、等离子爆破、持续激光与追踪导弹有独立节奏和命中表现；12 种随机机制改变发射、伤害组成、热量或防御。悬浮、周期冲刺、履带底盘改变移速和外观；装甲提供屏障、减伤或修复，核心提供超频、充能或暴击。攻击和移动特性可以组合。
- **战场环境层次**：四个区域分别加入油污焦痕、霜缝冷雾、风蚀沙纹与甲板检修口/电弧；建筑具有底座阴影和轮廓灯，战舰停泊坪与已发现设施有独立地面标识。地砖旋转、色差与磨损分布保持确定性，缩远时减少细节；迷雾末层遮罩与柔化边缘保留未知区域，所有装饰都不改变碰撞、寻路或发现进度。
- **实时 3D 战舰与敌军**：母舰、战场战舰、守卫、突击兵、炮兵、无人机及四个区域 Boss 使用原创低多边形硬表面模型。Boss 履带与炮台随部位破坏消失，过载核心脉动；模型按材质合批，离屏敌军不绘制，旧视口自动回收。
- **实时 3D 骨骼机甲**：赤鸢、夜莺、白隼采用原创低多边形硬表面模型，造型分别突出火力背架、四刃高速翼组和重装骑士披肩；每台有15根骨骼，装甲和武器刚性绑定到实际关节。战场、训练场和整备预览实时渲染三维姿态，再合成到现有2D地图；不再拉伸整张机甲立绘。造型不锁定武器或改变机体数值，原画保留用于收藏卡片。模型源文件和结构见 `assets/models/README.md`。
- **走跑与转向**：实际位移驱动行走/跑动步频和幅度，双腿两段IK保持支撑脚落地、抬腿弯膝、脚踝回正，速度变化平滑混合。相机投影与八方向地图行进匹配；机体连续转过360度，上身瞄准与腿部移动分离，后撤仍朝向目标。悬浮收腿、冲刺喷焰、履带底盘及滚动履带片各有三维姿态。
- **3D 武器与护盾**：连射炮、双轨炮、等离子、激光/脉冲、导弹、剑、拳套、重锤和手持盾使用独立三维几何；躯干、核心与背包反映当前配装。枪口光束取实际模型挂点，剑光带跟随真实剑尖，肩肘腕按攻击时序挥剑、三段出拳或举锤落锤。能量盾沿同一装甲几何与骨骼显示低透明边缘，受击只亮来弹侧，不填满机体中心。
- **检视与局部反馈**：进入“机甲整备 → 动作与特效检视”可切换三台机体、待机/步行/跑动/悬浮/冲刺/履带、五类武器及360度转向，默认自然持械，使用独立“攻击演示”开关观察抬枪、射击与收势；支持暂停、半速与护盾受击演示，隔离真实资源。落脚、刹停、冲刺起步、命中/击破、发现、回收、维修与排热由实际事件触发；特效数量和生命周期受限，不参与玩法随机或伤害判定。
- **近战与格斗**：制造工坊优先展示焰刃能量剑、破阵动力拳套、震岳重型战锤，均可装配左右手。能量剑射程120，前摇0.18秒后作120度扇形横斩；拳套射程84，在0.10/0.24/0.40秒打出三段独立命中的格斗连击；重锤射程108，前摇0.36秒后作100度重击。命中按实际距离、朝向和地形判定，每段对同一目标最多命中一次；移动出拳路、离开近战范围或借助障碍可躲开。三者分别造成热能160%、动能每拳62%、动能280%伤害，具有各自的热量、重量、冷却及收招，攻速不会令连击重叠。自动巡航装有近战武器时会贴近目标，混装枪械也以近战距离接敌，两手仍独立攻击；可选择“近战贴身”战术，手动走位仍可接管。训练与挂机认证使用同一套近战命中规则，统计单列近战伤害。区域掉落和挂机回收也能获得近战武器，随机机制仅使用兼容的电离或超温，不附加弹丸专用机制。
- **手持盾牌**：堡垒防暴盾可装在左手或右手，另一手搭配剑、拳套或枪械；盾牌本身不发射攻击，配装至少需要一件攻击武器。自动面向交战目标，对正面120度内的直射攻击格挡60%伤害并消耗等量格挡耐久；侧后方攻击与地面范围伤害不能格挡。精良/稀有/史诗的基础耐久为60/80/100，随部件等级成长；耗尽后破防2秒，停止受击2秒后每秒恢复12耐久。格挡耐久与原有能量护盾独立，朝向、耐久和破防恢复会保存；战斗界面显示格挡状态和正面防守弧线，训练与认证共用实际弹道方向和格挡规则。
- **制造工坊**：制造统一位于母舰首页“整备与构筑”组的“制造工坊”。按部位查看蓝图，选择型号后显示特性、随机规则和费用，再确认制造一件，消耗 450 信用点与 15 合金芯。全部基础型号及已解锁的命名蓝图均可制造；未解锁蓝图显示条件，材料不足或仓库满时不能确认。制造完成展示成品并收入仓库，不自动替换当前配装。整备页、部件仓库及区域详情不再提供直接制造按钮。
- **获取与整备**：普通胜利有 30% 概率掉落部件，每 5 战首领必掉史诗。分解精良/稀有/史诗返还 6/12/18 合金芯并积累对应机制研究。仓库支持比较、装配、锁定、机制筛选、勾选批量分解及保留词条升级；已装备、预设引用、锁定与待选重铸部件受到分解保护。旧收藏会自动合并为锁定。主仓上限 120，满仓阻止制造；战斗掉落保存在母舰溢出仓。
- **机师**：母舰休息室内可查看战术档案、切换主战、完成个人任务与交流。绯夜排热并发射扇形齐射，鸦羽贯穿并标记目标，凛提供临时护盾与持续维修；三人各有独立被动和探索特长。训练场与挂机认证共用技能逻辑。个人任务与信赖解锁故事、交流和归航徽章，关键战斗能力从加入时完整开放。所有已招募机师仍共同贡献基础攻击。
- **剧情与机师演出**：序章“留一盏归航灯”开启寻找民用撤离航路的故事，四张地图分别有出击简报、首领前对话和归航结局。另有三名机师的主战交流、凛的首次入队、首次撤离与战败回收剧情。凛入队后参与各章主线；个人任务和信赖交流也使用立绘、说话者切换与逐字对话，共37段可阅读内容。序章回应会在首次归航时被记起。长对话暂停战斗，点击可显示全文或继续，也可跳过本段；进度保存到具体台词。
- **机师带教**：新玩家由绯夜、鸦羽引导完成出击、手动移动、选择护航战术、现场回收、回舰、机甲整备和首次交流。界面显示当前目标并突出实际按钮，只有完成对应操作才推进。点目标卡或“操作说明 → 机师带教”可暂停、继续或重新学习；老存档不会强制重做。
- **航行日志与战场通讯**：剧情只在首次解锁时自动排队，看完或跳过后不再自动播放；归航时移入档案的未读简报、首领对话也不会在下次出击重复弹出。母舰“舰务与档案 → 航行日志”可主动阅读或回看已发现的主线、个人任务与交流，回看不重复发奖。主战机师会在发现首领、回收设施、击破目标、低装甲和实际释放技能时出现短通讯或技能立绘，短通讯不暂停战斗、不拦截走位。可在航行日志内关闭短通讯；训练和自动清剿演练不推进剧情或带教。
- **招募**：首次招募必得凛，后续每次随机让一位机师等级 +1，三人等概率。单抽 100 星晶，十抽 1000 星晶。
- **回收与挂机**：母舰“前线补给仓”内可认证回收方案。已控制区域需要连续三次真实自动清剿，保存装备/机师/战术快照，以实际耗时和生存稳定性决定效率。更换当前装备不改旧回收方案，在线探索期间也累计。前24小时全额，24—72小时半额，超出停止；最多折算48小时收益。领取信用点、合金、真实区域装备、研究资料与样本，满仓装备进入溢出仓。
- **行动任务**：完成战斗、强化、招募目标领取额外星晶。
- **云端档案**：母舰首页“舰务与档案 → 云端档案”内可创建账号，保存、下载完整进度；行动任务在“机师与成长”组独立展示。切换设备前保存；旧版本会被拦截，下载前自动备份本机。绑定云账号后采用服务器计时与联网发奖，领取请求可在断线后恢复，跨设备不会重复到账。原本机模式继续可用。后端运行与部署见 [server/README.md](server/README.md)。

## 工程与存档

用 Godot 4.7.2 打开 `project.godot`，按 F6/F5 运行。项目自带的 Godot 可执行文件仅位于 `tools/Godot.app`，没有安装到系统目录。所有工具依赖均在本项目内。

Android 测试包：在 macOS 上双击 `export_android.command`，或运行 `./export_android.command`。首次打包需要联网下载 Java 17、Android SDK 和匹配的 Godot 模板；SDK 安装时按提示阅读并接受许可。依赖与测试签名保存在项目的 `tools/android/`，缓存和日志在 `.local/android-build/`，不安装系统工具或修改 shell 配置。`./export_android.command --check` 可仅检查依赖。

成功后将生成 `build/android/crimson-front-test.apk` 和 SHA-256 校验文件；脚本验证签名、游戏资源及 32/64 位 ARM 运行库后才更新成品。测试版包名为 `com.crimsonfront.game.testing`，使用固定保留的本地测试密钥签名，请保留 `tools/android/test.keystore` 以便后续覆盖安装。把 APK 发给测试者，在安卓手机允许该来源安装应用后打开安装；本机存档和离线游戏可独立使用，云端功能需在游戏内配置可访问的服务地址。此脚本生成的是测试分发包。

- `scripts/state.gd`：战斗、经济、养成、存档。
- `scripts/parts.gd`：25 种部件蓝图（21 种基础、4 种首通命名蓝图）、12 种兼容机制、随机品质与词条、独立配装、成长研究、重铸、统一锁定、溢出仓和存档校验。近战与盾牌蓝图追加为21—24，原命名蓝图17—20保持不变。
- `scripts/melee.gd`：三种近战武器的射程、前摇、有效帧、收招、朝向、伤害与武器造型；攻击系统、自动战术和训练共用这些规则。
- `scripts/hand_shield.gd`：手持盾牌的格挡角度、耐久恢复与破防规则、武器造型和格挡状态绘制。
- `scripts/mechs.gd`：独立机库、三种机体型号特性、各机体永久随机词条、机体等级与存档校验。旧存档的三组配装按原索引迁移到对应机体，保留全部部件、预设和机师成长；新增机体等级从 1 级开始。
- `scripts/manufacturing_ui.gd`：独立制造工坊，统一蓝图列表、部位筛选、费用确认、实时材料/容量校验和制造收据。
- `scripts/recycle_ui.gd`：仅展示可分解部件、逐件勾选、当前筛选全选/清空、选中收益预览和确认时重新校验。
- `scripts/world.gd`：程序地形、分块缓存、分段 A* 寻路、据点、巡航和地图存档。
- `scripts/enemy_ai.gd`：敌军警戒、追击、绕障寻路、独立射击、脱战返航与附近单位缓存。
- `scripts/tactics.gd`：实战与训练共用的目标优先、距离保持、危险区避让、生存与技能时机策略。
- `scripts/story_content.gd`、`scripts/narrative.gd`、`scripts/story_ui.gd`：主线与机师对话、剧情触发与存档、立绘演出、战场通讯和实际操作带教。
- `scripts/region_data.gd`：四区掉落池、地图生成、地点布局、连通道路与敌军参数。
- `scripts/carrier_system.gd`、`scripts/carrier_ui.gd`：母舰永久改造、每趟支援弹药、共用冷却、真实炮击/维修与物资兑换。
- `scripts/carrier_ops.gd`：战舰定点警戒、近舰火控、舰能、三轮齐射、定点屏障、驻舰补给与贡献记录。
- `scripts/expedition.gd`：实地开雾、地点发现、现场交互、自主首领挑战、警戒、定向掉落、样本兑换、蓝图解锁与探索结算。
- `scripts/certification.gd`、`scripts/certification_actor.gd`：独立的真实自动战斗认证实例，不消耗实际玩家状态；复用实战控制器、私有随机源和敌军逻辑。
- `scripts/salvage_ledger.gd`、`scripts/salvage_ui.gd`：24/72小时积分、认证快照、跨方案分账、小数进度、回收结算与界面。
- `scripts/world_map.gd`：主界面地图镜头、拖图/摇杆/多点触控与地图内战斗。
- `scripts/main.gd`：竖屏界面和触控交互。
- `scripts/battlefield.gd`：2D 机甲绘制和战斗特效。
- `assets/pilots/pilots.png`：三位机师原图；制作提示词见 `assets/ART.md`。
- `build/web/`：标准 Godot H5 导出，支持普通静态服务器。
- `publish/dist/`：静态托管包，WASM 使用 gzip 流式解压。

本地进度在项目 `.local/save.json`；H5 进度在当前浏览器的 IndexedDB。部件的随机结果、唯一编号和三台机甲的配装也会保存，兼容没有部件字段的旧存档。自动存档、操作即时存档和离开页面存档均已接入；清理浏览器站点数据会重置进度。存档不是账号云存档。

## 构筑系统开发进度

新增随机机制：同一型号可以生成兼容的贯穿、跳弹、分裂、脉冲、扫射、蜂群、近爆、燃烧、电离、超温、排热护盾或承伤反击。标签限定兼容池，每件只保留一个机制；武器与核心机制可组合。旧装备不会重新随机。弹丸实际飞行，移动目标可以躲开，地形会阻挡。白炽粒子束持续追踪射线，脉冲需要蓄光；鸢尾导弹有限转向追踪，蜂群分摊伤害预算。燃烧有有限次数和真实范围，电离将原伤害拆分后结算。衍生攻击有命中名单、次数、深度、数量上限与触发系数。

母舰新增“构筑训练舱”和“配装档案库”。训练使用当前主战配装进行 30 秒测量，显示累计伤害、DPS、命中和机制触发，并按左右武器/技能/反击、动能/热能/电能、直击/光束/爆炸/灼烧拆分实际伤害；左右武器独立射程、冷却和连发，共享热量，统计降频时间。生存场景通过敌军移动、开火与弹丸碰撞造成承伤，可拖动走位；防御、修复、排热、反击及三位机师的独立技能与实战共用规则。训练不扣真实装甲、不产奖励。每台机甲可保存三套配装，预设引用的部件不能分解；应用预设会从其他机甲转装相应部件。

部件详情仅保留一个锁定标记（旧收藏自动迁移），并可进入“升级 / 校准”。每件只能选择一个数值词条作为校准位，重铸固定消耗 C150 / 合金8，结果三选一或保留旧结果；未选结果会保存，刷新后继续选择。升级每级增加 10% 基础属性与数值词条效果，保留型号、品质、词条和机制；每推进 5 场开放一级，上限 20 级。拆解含机制部件积累 1/2/3 点研究，达到 6 点永久解锁，以 C400 / 合金20 为兼容装备定向安装机制。

仓库默认按武器、躯干、腿部、核心、背包分组，显示各组数量，左右手通用武器合并展示；可切换“全部”或单个部位，从机甲槽位进入时直接筛选对应部位。当前机体装备使用绿色角标与高亮边框，其他机体装备使用蓝色，闲置部件标记“未装备”；所属机体和实际装配槽位单独显示，左右手武器按实际槽位标注，品质颜色仍保留。部位可与机制及“只看锁定”筛选组合。批量分解默认不选择任何部件，可逐件勾选、全选当前可分解项或清空；预览仅包含本次勾选的部件，返回后保留选择，确认前再次校验。批量分解列表仅显示当前筛选下可分解的闲置部件；已装备、锁定、预设引用及待选重铸的部件自动隐藏。已选部件若随后被装备或锁定，也会从列表和选择中立即移除。主仓满时，全部战斗掉落保存到母舰“掉落溢出仓”，保留完整随机结果，腾出空间后取回。基础武器制造允许选择实弹、轨道炮、等离子、激光或导弹型号，品质和词条仍会随机。

自动战术随每台机体独立保存，也可随三套配装方案保存/恢复；旧配装档案继续可用。控热模式在热量达到80，或即将开火会超过95时停火，冷却至45后恢复，刷新期间也保留停火状态；双手交替模式会完成一轮三连射再换手，只有一手能到达目标时继续单手射击。交战距离兼顾两手武器，以较短有效射程为准，近战优先。配装自适应中，主手轨道炮/光束停步射击、导弹远距游击、等离子近距压制；鸦羽停步以触发稳态瞄准，凛远程保持距离，夜莺与白隼不持续绕圈。明确选择近距/远距/近战距离时优先遵循玩家设置；站定仍会规避首领危险区；对260范围内正朝机体飞来的直射弹丸，会侧移离开弹道，远离或飞过的弹丸不触发规避。护盾撤离在护盾≤20%时拉开距离、恢复到60%后返回；装甲≤30%时回舰，训练中则记录安全撤离。手动锁定 Boss 部位和手动技能优先于自动策略。

探索中开启武器库、击败精英会产出所选型号的稀有部件；普通敌军随机掉落本区域部件，每次击破守军奖励样本1。首次击败区域首领获得对应命名蓝图和一件史诗成品，并解锁后一区域；重复击破产出所选型号的史诗部件。首领奖励样本8，首次额外奖励8。样本12可兑换指定基础型号的稀有部件，样本20可兑换已解锁的命名史诗；满仓进入溢出仓。命名蓝图可按 C450 / 合金15 制造，出厂机制占正常机制位。此前已击败掘墓者的旧存档保留白噪冷却站及首个命名蓝图。

回收认证只对已通关首领的区域开放，不会通过模拟解锁未击败的首领。认证档案可独立启用，保留其当时的配装和战术；后台回收队按该快照工作。切换前先按旧方案记账，所有方案共享同一领取周期的24/72小时额度；领取后重置累计周期，未满一份的装备、材料与货币小数进度继续保留。分账界面同时保留当前未领与上次结算来源。挂机装备来自认证区域基础掉落池，命名部件仍需首通、制造或样本兑换；“精良自动分解”只处理本次新掉落的精良装备，稀有以上不自动销毁。研究资料可在部件校准的机制研究界面定向投入。
